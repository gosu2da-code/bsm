## 0. 함께 일하는 방식 (가장 중요)

- **맹세:** 사용자가 **"만들어" / "고고" / "ㄱㄱ"** 처럼 분명히 말하기 전에는 파일을 만들거나 코드를 고치거나 커밋하지 않는다. 그 전까지는 의논·질문·조사만 한다.
- **의논이 먼저**, 질문은 **한 번에 하나씩** (사용자가 "휴먼의 한계" 라고 함). 추천안이 있으면 함께 제시.
- 글꼴·색·크기처럼 **눈으로 봐야 아는 것은 앱에 넣기 전에 시안(PNG)부터** 보여준다. (D2Coding 글꼴을 바로 적용했다가 되돌린 일이 있음)
- 사용자가 먼저 꺼내지 않은 주제를 앞서 꺼내지 않는다 ("후반부에 말하려고 했는데" 사례).
- 사용자는 **노트북(=태블릿과 같은 넓은 화면) 90%**, 휴대폰은 가끔. 휴대폰은 "깨지지만 않으면 OK".
- 사용자는 **미국 주식만** 본다 ("사나이는 미장"). 국내 종목 검증은 신경 쓰지 않아도 됨.
- 설명은 쉬운 한국어로. 주식·기술 용어는 풀어서.
- 투자 조언(매수·매도 추천, 주가 예측)은 하지 않는다. 데모의 가짜 줄거리를 실제 신호처럼 말하지 않는다.

| 업데이트 | `src`, `public` 은 컨테이너에 직접 연결돼 있음 → **파일 덮어쓰기 → (src 면) 다시 시작 → 새 탭**. 자세한 건 README |

### 겪었던 함정
- 시놀로지 "빌드" 는 **이미지가 이미 있으면 그대로 재사용** → 이미지 새로 만들 땐 **중지 → 정리 → 이미지 삭제 → 빌드**.
- `data` 폴더가 없으면 시작 실패 (`Bind mount failed`) → File Station 에서 만든다.
- 맥에서 업로드할 때 점(.)으로 시작하는 파일이 빠짐 (Finder `⌘ + Shift + .`).
- 압축 푼 폴더를 통째로 올리면 엉뚱한 곳에 들어감 → 안의 파일을 해당 폴더 안으로.
- 업데이트 후 **예전 탭이 예전 화면 코드로 계속 동작** (실시간 연결은 자동 재연결) → 탭을 닫고 새 탭.
- 토스 토큰은 **키 하나당 1개만 유효** → 같은 키로 두 군데서 돌리면 서로 끊음 (앱은 5분 대기로 방어).

## 2. 확정된 사양

### 시세와 등락률
- 실시간: 토스 웹소켓 체결(연결 1개, 최대 100종목). 끊기면 10초마다, 살아 있어도 60초마다 REST 로 현재가 확인. 화면은 1초마다 갱신.
- **등락률 기준 = 전 거래일 정규장 종가** (일봉, 수정주가). 거래일은 토스 장 운영 정보로 판단 (데이마켓이 열리면 새 거래일).
  - 2026-11-03 토스 앱과 비교해서 기준가가 일치함을 확인 (MU $833.59, SNDK $1,075.08).
- 색: **상승 빨강 · 0.00% 회색 · 하락 파랑** (소수 둘째 자리 반올림 기준).
- 섹터 숫자 = 구성 종목 등락률의 **단순 평균** (데이터 없는 종목 제외).
- 종목은 고유 기준 최대 **100개** (101번째부터 추가 막음). 티커는 영문 그대로(`MU`).

### 편집
- 화면에서 섹터·종목 추가/수정/삭제. 티커 입력 시 토스로 확인해 종목명·ETF 여부 표시.
- 한글 입력 중 엔터 두 번 문제 해결됨(`isComposing`), 연속 클릭 중복 방지.
- 편집 버튼 → **카드형 편집 화면**, 완료 → 줄기 트리.
- 저장: NAS `data/sectors.json`.

### 정렬
- 등락률순(기본) / 넣은 순서 전환 버튼. 1초마다 정렬, **0.1%p 넘게 앞설 때만 추월**, 이동 애니메이션.

### live / each (마켓별 등락)
- **live:** 어제 정규 종가 대비. 옆 막대(데이·프리·정규·애프터)는 **읽기 전용 진행 표시** (포함=초록, 아직=옅은 초록, 애프터=회색).
- **each:** 고른 마켓 **안에서만** 오르내린 폭. 누르면 숫자가 흐려지고 **아무것도 선택 안 된 상태**로 시작, 고르는 순간 반짝 ("빨간 옷 심리").
  - 데이 = 어제 정규 종가 → 데이 마지막 / 프리 = 데이 마지막 → 프리 마지막 / 정규 = 프리 마지막 → 정규 종가 / 애프터 = 오늘 정규 종가 → 애프터 마지막. 그래서 데이+프리+정규 = live.
  - 체결 없는 종목은 `–`, 평균에서 제외. 체결 있고 0% 면 `0.00%` (평균에 포함).
  - 오늘 아직 안 열린 마켓은 비활성, 날짜 선택으로 지난 거래일 조회. 기록은 `data/sessions.json` 에 90일치.
  - live 에서 오늘 거래 없는 종목은 `0.00%` 그대로 (대세 콜).

### 상단 한 줄
`섹터 트리 ● 실시간 │ [live|each] [데이][프리•][정규][애프터] (날짜)   종목 n/100  시각  [정렬] [편집]`
- ● 실시간 / ● 10초 조회 / ● 연결 끊김 (점 + 글자). 국내·미국 장 칩은 없음.

### 줄기 트리 (보기 화면)
- **가운데 세로 줄기.** 왼쪽 = + 섹터 (0.00%, `–` 포함, 큰 순서로 위부터, `0.00%` → `–` 는 아래), 오른쪽 = − 섹터 (− 큰 순서로 위부터). 0선을 넘으면 **바로** 반대편으로 ("일 열심히 하네").
- 종목은 **상위 섹터를 따라가고** 순서도 섹터 방향(+ 큰 순 / − 큰 순)을 따름.
- 섹터 이름은 **줄기 옆 한 줄**. 종목 묶음은 순위에 따라 **가까운 열 / 먼 열 지그재그** (1위 가까이, 2위 멀리…).
  - 가까운 열: 선이 묶음 **맨 위**에 닿고 아래로. 먼 열: 묶음 **맨 아래**에 닿고 위로 (선이 다른 묶음을 가로지르지 않게 — 사용자 컨셉카에서 나온 설계).
- 비대칭(한쪽 쏠림)은 그대로 둠 = **여백의 미 + 시장 폭 신호**.
- 스타일 = **시안 ⑪**: 글자 종목 10px / 섹터 11px 보통 굵기, 선 0.75px 회색, 줄기 1.5px 회색, 줄 간격 26, 가로선 가까운 열 170 / 먼 열 330.
- 글꼴: **JetBrains Mono (구글 글꼴) + 맥 기본 한글** — D2Coding 은 시도했다가 원래 것이 더 낫다고 해서 되돌림.
- 테마: 컴퓨터 설정(밝게/어둡게) 따라감.

## 3. 보류 / 아이디어

| 항목 | 상태 |
|---|---|
| 같은 시각 캡처로 토스와 소수점까지 비교 | 보류 |
| 휴장일·빈 시간대(08:00~10:00) 예외 처리 보강, 장 정보 못 받을 때 예비 로직 | 보류 |
| 종목이 많을 때(50~100) 한 화면 문제: 줄 간격, 3열, 스크롤 등 | **실전에서 써 본 뒤** 결정 |
| **빨간 시소선**: 반대로 움직이는 두 섹터를 수동 연결. 줄기를 가로지르면 시소 작동 중, 같은 쪽이면 깨짐 | 확정된 컨셉, 미구현 |
| 선 모양·색으로 의미 표현 (예: 소형주·비AI 섹터는 쇄선, 파생 ETF 는 점선) | 컨셉 (뜻은 나중에) |
| 상자로 섹터 묶기 (상위 그룹) | 컨셉 |
| 섹터 안의 섹터 (한 단계 더, 레버리지 ETF 를 본주 밑에 등) | 가능성만 확인. 넣을 땐 접기/펼치기, 파생은 평균에서 제외 추천 |
| 순환매 지도 / RRG 오마주 (상대강도 × 모멘텀 4분면, "RRG" 는 상표라 다른 이름) | 경험이 쌓인 뒤 |
| 가격 알림 (예: 전일 종가 아래로) | 아이디어만 |
