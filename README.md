# 섹터 트리

토스증권 Open API 시세로 **섹터별 종목을 트리 형태로** 보여주는 개인용 대시보드입니다.

```
 ┌────────────────┐
 │ 메모리 +0.25%  │- - - - - - - - ╮
 └──┬─────────────┘                 ╎
 ╎  │                               ╎
 ╎  ╰──────────   SNDK  +3.00%      ╎
 ╎  │                               ╎
 ╎  ╰──────────   MU    -2.50%      ╎
 ╰ - - - - - - - - - - - - - - - - -╯
```

- 상승 **빨강** · 0% **회색** · 하락 **파랑**
- 섹터 라벨의 등락률 = 구성 종목 등락률의 **단순 평균**
- 화면에서 섹터·종목 **추가 / 수정 / 삭제** (티커를 입력하면 종목명·ETF 여부를 확인해 줌)
- 종목은 여러 섹터에 겹쳐도 1개로 세고, **최대 100개**까지 등록 가능
- 시세: 토스 **웹소켓 실시간 체결** → 화면은 **1초마다** 갱신
  - 웹소켓이 끊기면 10초마다 REST 로 현재가 조회 (동작 중에도 60초마다 한 번 확인)
  - 등락률 기준(전 거래일 종가)은 일봉으로 계산해서 거래일이 바뀔 때만 다시 받음
- **줄기 트리 화면**: 가운데 줄기 하나. 왼쪽은 오르는 섹터(+, 0.00%, 데이터 없음 `–` 포함), 오른쪽은 내리는 섹터(−).
  섹터 이름은 줄기 옆에 한 줄로 서고, 종목 묶음은 순위에 따라 가까운 열 / 먼 열로 번갈아 놓입니다.
  종목은 상위 섹터를 따라가며, 섹터가 0선을 넘으면 줄기 반대편으로 건너갑니다. 편집 버튼을 누르면 카드형 편집 화면으로 바뀝니다.
- **정렬**: 섹터는 평균 등락률 높은 순(왼쪽 위부터), 종목은 섹터 안에서 높은 순(위부터). 1초마다 다시 줄 세우고, 0.1%p 넘게 앞설 때만 자리를 바꿉니다. 오른쪽 위 버튼으로 "넣은 순서"로 바꿀 수 있고, 편집 중에는 넣은 순서로 고정됩니다.
- **live / each**
  - **live**: 어제 정규장 종가 대비 등락률. 옆 막대(데이·프리·정규·애프터)는 누를 수 없는 진행 표시입니다 (초록 = live 숫자에 포함, 회색 애프터 = 포함 안 됨)
  - **each**: 고른 마켓 **안에서만** 오르내린 폭. each 를 누르면 숫자가 흐려지고, 마켓을 고르는 순간 바뀝니다
    - 데이 = 어제 정규 종가 → 데이 마지막 / 프리 = 데이 마지막 → 프리 마지막 / 정규 = 프리 마지막 → 정규 종가 / 애프터 = 오늘 정규 종가 → 애프터 마지막
    - 그래서 데이 + 프리 + 정규 = live
    - 그 마켓에서 체결이 없던 종목은 `–` 로 표시하고 섹터 평균에서 뺍니다 (체결이 있었는데 0% 면 `0.00%`)
    - 오늘은 아직 안 열린 마켓을 고를 수 없고, 날짜를 바꾸면 지난 거래일 기록을 볼 수 있습니다
    - 마켓별 가격은 앱이 켜져 있는 동안 기록되어 `data/sessions.json` 에 90일치 저장됩니다 (앱이 꺼져 있던 마켓은 `–`)
- **시세 조회 API만 사용합니다.** 주문·계좌 관련 코드는 들어 있지 않습니다.

## 1. 준비물

1. 토스증권 WTS > 설정 > Open API 에서 발급받은 **Client Id / Client Secret**
2. 같은 화면의 **허용 IP** 에 NAS 가 인터넷에 나가는 공인 IP 가 등록되어 있어야 함
   - 집 공유기 아래의 NAS 라면 보통 PC 와 같은 공인 IP 입니다.
   - NAS 의 Tailscale 이 **exit node(출구 노드)를 사용** 중이면 다른 IP 로 나가므로 차단됩니다.
3. Synology DSM 7.2 이상 + **Container Manager** 패키지

## 2. NAS 에 설치 (Container Manager)

1. **File Station** 에서 `docker/sector-tree` 폴더를 만들고 이 저장소 파일을 모두 올립니다.
   (GitHub 에서 *Code → Download ZIP* 으로 받아 압축을 풀어 올리면 됩니다)
2. `.env.example` 을 복사해서 **`.env`** 로 이름을 바꾸고 키를 채웁니다.
   ```
   TOSS_CLIENT_ID=tsck_live_...
   TOSS_CLIENT_SECRET=tssk_live_...
   PORT=3000
   MOCK=0
   ```
   > `.env` 는 비밀번호 같은 파일입니다. 다른 사람과 공유하거나 GitHub 에 올리지 마세요.
3. **Container Manager → 프로젝트 → 생성**
   - 프로젝트 이름: `sector-tree`
   - 경로: `docker/sector-tree`
   - 소스: **기존 docker-compose.yml 사용**
   - 다음 → 완료 (이미지를 빌드하고 실행합니다. 처음엔 1~2분 걸려요)
4. 브라우저에서 접속합니다.
   - 집 안: `http://NAS내부IP:3000`
   - 밖(Tailscale): `http://NAS의-Tailscale-이름:3000`

섹터·종목 구성은 `docker/sector-tree/data/sectors.json` 에 저장되어 컨테이너를 다시 만들어도 유지됩니다.

### 업데이트할 때
`src` 와 `public` 폴더는 컨테이너가 NAS 폴더를 바로 읽기 때문에, 빌드할 필요가 없습니다.

1. 새 파일을 같은 폴더에 덮어씁니다 (`.env` 와 `data` 폴더는 그대로 두세요)
   - 압축을 푼 폴더를 통째로 올리지 말고, `src` 안의 파일은 NAS 의 `src` 안으로, `public` 안의 파일은 NAS 의 `public` 안으로 올리세요
2. **Container Manager → 프로젝트 → sector-tree → 작업 → 다시 시작**
   - `public` 만 바뀌었다면 다시 시작도 필요 없습니다
3. 앱 화면 탭을 닫고 새 탭에서 엽니다 (또는 `⌘ + Shift + R`)

> 업데이트가 됐는지 확인하는 법: 업데이트 안내에 적힌 새 주소나 기능이 보이는지 확인하세요.
> `package.json`, `Dockerfile`, `docker-compose.yml` 이 바뀌었을 때만 아래처럼 이미지를 새로 만들어야 합니다.
> **중지 → 정리 → 이미지(`sector-tree-sector-tree`) 삭제 → 빌드**
> (시놀로지의 "빌드" 는 이미지가 이미 있으면 그대로 다시 쓰기 때문에 이미지를 지워야 새로 만들어집니다)

> `data` 폴더가 없으면 시작이 실패합니다 (`Bind mount failed`). 그때는 File Station 에서 `data` 폴더를 만들어 주세요.

## 3. 화면 위 상태 표시

| 표시 | 의미 |
|---|---|
| 국내 / 미국 `정규장`·`프리마켓`·`장 마감` 등 | 토스 장 운영 정보 기준 현재 세션 |
| 🟢 실시간 | 웹소켓으로 체결가를 받는 중 |
| 🟠 10초 조회 | 웹소켓이 연결되지 않아 REST 로 조회 중 |
| 종목 37 / 100 | 등록된 고유 종목 수 |

### 노란 경고가 뜰 때

| 메시지 | 해결 |
|---|---|
| 허용되지 않은 IP예요 | 토스 WTS > 설정 > Open API > 허용 IP 에 현재 공인 IP 추가 (가정용 인터넷은 IP 가 가끔 바뀜) |
| Client Id / Secret 이 올바르지 않아요 | `.env` 값을 다시 복사한 뒤 프로젝트 재시작 |
| 다른 곳에서 같은 키로 토큰을 발급했어요 | 토스 토큰은 **키 하나당 1개만 유효**합니다. PC 등 다른 곳에서 같은 키로 이 앱(또는 다른 프로그램)을 돌리고 있다면 꺼 주세요. 서로 끊는 걸 막기 위해 5분 뒤에 다시 시도합니다 |
| 토스증권 시스템 점검 중이에요 | 점검이 끝나면 자동으로 돌아옵니다 |

## 4. 알아둘 점

- **같은 키로 이 앱을 두 군데서 동시에 돌리지 마세요.** (토큰 1개 제한)
- 웹소켓은 계정당 동시 연결 2개까지라서, 이 앱은 **1개만** 사용합니다.
- 서버 로그에 `체결 메시지에서 가격을 찾지 못했어요` 가 보이면 토스 실시간 메시지 형식이 예상과 다른 것입니다.
  그 로그 한 줄을 알려주시면 맞춰서 고치겠습니다. (그동안에는 10초/60초 REST 조회로 계속 동작합니다)

## 5. 개발용

```bash
npm install
npm run mock     # 가짜 데이터로 실행 (토스 접속 없음) → http://localhost:3000
npm test         # 거래일·기준가 계산 테스트
```

| 파일 | 역할 |
|---|---|
| `src/server.js` | 웹 서버, 편집 API, 화면 1초 갱신(SSE) |
| `src/toss.js` | 토스 REST 클라이언트 (토큰 관리, 호출 한도, 재시도) |
| `src/realtime.js` | 토스 웹소켓 (구독, PING, 재연결) |
| `src/quotes.js` | 실시간 + REST + 기준가를 합쳐 등락률 계산 |
| `src/market.js` | 장 운영 정보로 거래일·세션 계산 |
| `src/sessions.js` | 마켓별(데이·프리·정규·애프터) 가격 기록과 each 등락률 계산 |
| `src/store.js` | 섹터·종목 저장 (`data/sectors.json`) |
| `src/mock.js` | 가짜 데이터 모드 |
| `public/` | 화면 (섹터 트리 SVG, 편집 패널) |
